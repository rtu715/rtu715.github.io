# rtu715.github.io

Personal homepage, plain static HTML served by GitHub Pages as-is (`.nojekyll`).
Edit `index.html` to update the bio or selected papers (each needs a 480x360 figure in `assets/img/papers/`);
the full list is `publications.html`. Styles for all pages are in `assets/style.css`; the font is self-hosted in `assets/fonts/` (SIL OFL). `robots.txt` asks AI-training crawlers to skip the site.
